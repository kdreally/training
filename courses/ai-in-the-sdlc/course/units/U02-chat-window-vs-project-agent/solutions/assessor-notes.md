# U02 Assessor notes

Assessor-only.

## Model answer sketch

**Q1:** A program on your computer, started from a terminal (CLI), aimed at a project folder, able to read and edit files there. It is not a website chat, not the author of record, not a brand name.

**Q2:** status update → chat (or neither if they argue it is a human writing task; accept chat). Change `borrow` → agent. Team taste about the name → neither. Find the test → chat if pasting the file, agent if searching the repo; reason must match.

**Q3:** The pasted file can be old; the reply can use a different error style; tests are not run unless the human does it; secrets in the paste leave the machine.

**Q4:** The human accepts. The agent's summary is a claim, not acceptance.

## Common weak submissions

- Defines the agent as "ChatGPT in the terminal" and then builds the whole answer on one brand. The definition can mention that brands exist, but the job must be stated without one.
- Labels the behavior change as chat because "AI can write the function." The work product is a repo change.
