# U11 Assignment — Repair the file

Submit `U11-YourName`.

## Files

### 1. `diagnosis.md`

Take the bad file in the U11 README (the "world-class team" example). Quote at least one fragment for each failure mode: vague, bloated, contradictory, task-stuffed. For the contradictory mode, quote both sides of one pair. State the secret problem in its own sentence and what a team should do if the password had been real.

### 2. `AGENTS.md`

Write the repaired standing file for shelf. It must not contain the demo password, the handbook, the microservice migration, the overdue task, or a library shopping list. It must remain something you would actually load.

### 3. `answers.md`

1. A teammate says the express rewrite "disobeyed instructions" because of the line "do not add dependencies without asking." Explain why the old file also permitted the rewrite. 4–6 sentences.
2. Why does adding the word IMPORTANT not repair "write clean code"?

### 4. `checklist.md`

```markdown
- [ ] I read the U11 README.
- [ ] The password string is not in my AGENTS.md.
- [ ] I read the rubric.
```

## Definition of done

Someone could replace the bad file with yours and no longer cite a bullet to justify `npm install express`.

## Submission format

```text
U11-YourName/
  diagnosis.md
  AGENTS.md
  answers.md
  checklist.md
```
