# U22 Assignment — Recover a turn

Submit `U22-YourName`.

## Files

### 1. `recovery.md`

You received the U17 fixture's generation (Express, lodash, date-fns, `src/services/LoanService.js`, deleted `test/loans.test.js`, rewritten server). Write:

1. **Stop.** The exact next message you will *not* send, and the one-sentence reason. (Quote a bad follow-up you refuse.)
2. **Revert.** Commands or manual deletes, path by path, that return shelf to the baseline. Include an untracked file and a modified tracked file.
3. **Tighten.** Five fence lines derived from that fixture.
4. **Retry ceiling.** What you will do if the second try deletes tests again.

### 2. `answers.md`

1. Why is sculpting with six small prompts more dangerous than a restore?
2. A password appeared in the agent transcript during the bad turn. What changes in the loop?
