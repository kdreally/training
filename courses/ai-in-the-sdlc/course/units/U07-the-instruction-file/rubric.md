# U07 Rubric

Visible to learners. Total **20 points**.

| Criterion | Points | Must-have? | Evidence |
|-----------|--------|------------|----------|
| Prose vs wiring defined; prose located at root `AGENTS.md` | 5 | Yes | Q1 |
| Six items sorted correctly | 6 | Yes | Q2 |
| Pointer file is short and names `AGENTS.md` as the source | 4 | Yes | Q3 |
| `package.json` description rejected as a policy home with a real reason | 3 | Yes | Q4 |
| `tool-notes.md` states both facts to look up | 2 | No | tool-notes |

### Sort key

1 wiring, 2 prose, 3 wiring, 4 task, 5 prose, 6 prose.

"Do not open a network connection" may be labeled wiring if they describe a permission, or prose if they describe a sentence. Award the point for either, as long as the sentence explains the choice. If they say both, award the point.

### Partial credit

- Q3: 2/4 if they paste a full duplicate policy into the second file. The lesson is drift.
- Q4: 2/3 if they only say "the agent might not read package.json." Give 3/3 if they also say the description is for humans and package managers, not a rule list.

### Must-have vs nice-to-have

`tool-notes.md` depth is nice-to-have, but the file must exist (covered by filenames in spirit). Missing must-have caps at 15/20.
