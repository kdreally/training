# U04 Rubric

Visible to learners. Total **20 points**.

| Criterion | Points | Must-have? | Evidence |
|-----------|--------|------------|----------|
| Three wrong starts, each with a distinct consequence | 7 | Yes | Q1 |
| Project-root definition is accurate (package.json, src, test) somewhere in the answer | 2 | Yes | Q1 |
| Prediction precedes real `pwd` / `Get-Location` output, or a honest failed search is documented | 5 | Yes | Q2 |
| Diagnosis names the wrong directory, the created files, the unwanted install, and a stop/restore step | 5 | Yes | Q3 |
| Filenames correct | 1 | Yes | folder |

### Partial credit

- Q1: 4/7 if two of the three wrong starts are solid.
- Q3: 3/5 if they identify the directory but then recommend a follow-up prompt from `D:\work`.

### Must-have vs nice-to-have

All rows are must-have. A miss caps the grade at 15/20.
