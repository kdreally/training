### Partial credit

- Required duties: file fence, dependencies, database/network, secrets, style, tests, honesty, commands, changelog. Score 1 each up to 8, and treat "style + tests" as two. If one is mush ("keep quality high"), score it 0.
- Near-copy of the README file: cap the `AGENTS.md` rows at half if the checklist claims original wording and the text matches the lesson verbatim. A close paraphrase with the same coverage is full credit. The goal is understanding, not synonym gymnastics. Verbatim plus a strong Q1 still passes; award at least 12/20 if Q1 shows they can apply the bullets.

### Must-have vs nice-to-have

Q2–Q3 are nice-to-have as a pair worth 2 points. Missing must-haves cap at 15/20.
