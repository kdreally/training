# U06 Assessor notes

Assessor-only.

## Model answer sketch

**Q1:** The repo is what every teammate and every tool can open. Git history shows who changed a rule. A rule inside shelf does not leak into a different repo. Chat memory fails all three.

**Q2:** standing (secrets), task (Friday demo), standing (force push), standing (error style), task (Sam's fixture). If item 4 is called a task because "prefer" is uncheckable, give the point.

**Q3:** Prompt like "add overdue loans." Guesses: `date-fns` dependency, a new Express route, a new `src/overdue.js`, a database. Blocking rule: "Do not add npm dependencies" or "Do not add HTTP routes unless the task names them."

**Q4:** The model may ignore the file. The file is what you cite during review. Acceptance is still the human plus tests.

## Common weak submissions

- Says the file is unnecessary if you write perfect prompts. That ignores fatigue and teammates.
- Puts "Sam's overdue book" in standing instructions.
