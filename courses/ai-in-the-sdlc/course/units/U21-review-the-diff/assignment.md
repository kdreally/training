# U21 Assignment — Decide from the diff

Submit `U21-YourName`.

## Files

### 1. `review.md`

Review the worked diff in the U21 README. Use the five-step order as headings. Under each heading, write what you found. End with `Decision: restore` or `Decision: accept`, and three citations (file plus what is wrong or right).

### 2. `answers.md`

1. Why is a partial keep ("leave the function, delete the import later") unsafe here?
2. **Predict.** If this diff were applied and you ran `npm test` without installing, what class of failure would you expect? You do not have to apply the diff. Say what is missing for the import to resolve, and whether a green run would be possible after `npm install`. Would that green run change your decision?
3. Write the `git` commands you would use on a real repo to see the stat and the full diff. One sentence on why you do not review only the agent's pasted summary.

### 3. `checklist.md`

```markdown
- [ ] I read the U21 README, including the diff.
- [ ] My decision cites a file.
- [ ] I read the rubric.
```

## Definition of done

A teammate can follow your five headings and reach the same decision.

## Submission format

```text
U21-YourName/
  review.md
  answers.md
  checklist.md
```
