# U01 Assignment — Destination and shelf

Submit one folder or zip named:

`U01-YourName`

## Files to submit

### 1. `answers.md`

1. **Five artifacts.** For each of standing instructions, spec, prompt, tests, and evaluation, write two sentences: what it is, and at what moment in a change you create or use it.
2. **Shelf.** Describe shelf to a developer who has not seen it. Include where logic lives, where tests live, the shape of a failed `borrow` result, and the fact that there are no npm dependencies. Mention `GET /loans`.
3. **Out of scope.** Name three things this course deliberately does not train, and give one sentence each on why leaving them out protects the course.
4. **Predict, then check.** Before you run anything, write the command you will use to print the Node version, and write what a successful line starts with. Then run it. Paste the real output under the heading `What actually happened`. If Node is missing, paste the error and decode it.

### 2. `checklist.md`

```markdown
- [ ] I read the U01 README fully.
- [ ] I can name the five artifacts without looking.
- [ ] I opened course/examples/shelf or used the quotes in the README.
- [ ] Question 4 has a prediction written before the real output.
- [ ] I read the U01 rubric.
```

## Definition of done

- Both files are present.
- Question 4 shows a prediction and either real output or a decoded "command not found."
- Answers are in your own words.

## Submission format

```text
U01-YourName/
  answers.md
  checklist.md
```
