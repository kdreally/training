# U01 Rubric

Visible to learners. Total **20 points**.

| Criterion | Points | Must-have? | Evidence |
|-----------|--------|------------|----------|
| All five artifacts defined, each with a moment in the workflow | 6 | Yes | `answers.md` Q1 |
| Shelf description matches the example: loans module, tests, error object, no dependencies, `GET /loans` | 5 | Yes | `answers.md` Q2 |
| Three out-of-scope topics, each with a reason | 4 | Yes | `answers.md` Q3 |
| Prediction written before the version check; real output or a decoded missing-command error | 4 | Yes | `answers.md` Q4 |
| Filenames and checklist present | 1 | Yes | folder |

### Partial credit

- Q1: 4/6 if one artifact is missing or if "when" is absent throughout.
- Q2: 3/5 if they describe a loan app but invent a database or an Express server.
- Q4: 2/4 if they show output with no prediction.

### Must-have vs nice-to-have

Every row is must-have. A miss caps the unit at 15/20 and is revise-and-resubmit for that row.
