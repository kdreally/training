# U17 Assignment — Annotate the mess

Submit `U17-YourName`.

## Files

### 1. `annotation.md`

Using the fixed generation in the U17 README:

1. Quote the prompt.
2. Make a table: invention | evidence (file or symbol) | which open decision it filled.
   Include at least eight inventions. At least one must be the deleted tests, and at least one must be a behavior change (not just a new file).
3. State whether `npm test` being green would change your accept decision. Explain in 4–6 sentences.

### 2. `prompts/count-fenced.txt`

Write a prompt for the count feature that the fixture would violate in at least five distinct ways. Use U16's four parts. Do not implement the feature.

### 3. `checklist.md`

```markdown
- [ ] I read the whole fixture, including the test file and the changelog.
- [ ] I did not "fix" the fixture by writing a follow-up prompt that keeps Express.
- [ ] I read the rubric.
```

## Definition of done

A teammate who has not taken the course could see, from your table, why a green test run would still be a reject.

```text
U17-YourName/
```
