# AI in the Software Development Life Cycle

Use a local coding agent inside a real project: standing rules, specifications, prompts, and the checks that decide whether generated code is acceptable.

## Who this is for

Working developers who already write code, use Git, and know what a feature, a bug, and a test are. The course does not teach a programming language, and it does not certify a vendor product. Confusion about *how* to direct an agent is treated as normal.

## How learning works

| Role | What they do |
|------|----------------|
| Learner | Reads static unit materials, writes specs and prompts, reviews fixed examples of generated code |
| Human trainer / assessor | Reviews submissions against each unit's rubric |
| Course author | Generates units from the teaching doctrine |

A live model is optional. Graded work is files a human can mark: instruction files, specs, prompts, tests, and written reviews.
