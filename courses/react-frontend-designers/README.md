# React.js Frontend for Designers

Turn design intuition into working React interfaces — components, props, state, styling, and shipping your first app.

## Who this is for

Designers (Figma comfortable) with little or no programming experience. Confusion is normal; every command and every React idea is explained before you use it.

## How learning works

| Role | What they do |
|------|----------------|
| Learner | Reads static unit materials, does exercises, completes assignments |
| Human trainer / assessor | Reviews submissions against each unit's rubric |
| Course author | Generates units from the teaching doctrine |
