# U00 Assessor notes

## Model answer sketch

**Q1:** Open unit → read outcomes/prereqs/why → teaching + vocab → worked example → common errors → checkpoints → practice → assignment + rubric → submit structured files.

**Q2:** Practice = learning reps; assignment = evidence for human marking. Copying without understanding fails explain-in-own-words and future units.

**Q3:** Last sense → first nonsense → vocab → re-run example → change one thing → write attempts → ask with notes.

**Q4:** Human trainer/assessor; rubric in the unit.

**Q5:** Any concrete pair (e.g. "I used to skip theory → I will read Why before tasks").

**Q6:** Examples: a component/symbol reused across screens; a text/color style; an auto-layout frame. The key is naming *what makes it reusable* (instances inherit changes, one edit updates all).

## Common weak submissions

- Only restates headings.
- Stuck protocol = "Google it."
- Claims they need no rubric.
- Q6 answer describes a one-off element that is never reused.
