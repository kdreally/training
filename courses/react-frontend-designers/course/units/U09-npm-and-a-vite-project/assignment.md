# U09 Assignment — A running Vite + React project

Submit the following to your trainer in **one folder or zip** named:

`U09-YourName`

## Files to submit

### 1. `answers.md`

Answer in your own words.

1. **npm's two jobs.** In 3–5 sentences, explain what npm is and the two jobs it does.
2. **Dev server.** What is a dev server? Explain, in your own words, what "hot reload" means and the manual step it removes.
3. **localhost and ports.** What does `localhost` mean? What is a port? What port did Vite use for you?
4. **Commands in order.** List, in order, the four commands you ran to go from an empty Desktop to a page in the browser (the `cd`, the scaffold, the install, the run). For each, one sentence on what it did.
5. **The scaffold choices.** You chose **React** and **JavaScript**. Why JavaScript and not TypeScript in this course? (One or two sentences. If unsure, say what you would ask the trainer.)
6. **Stop the server.** How do you stop the dev server, and what clue tells you it has stopped?
7. **Error-reading practice.** Describe the deliberate error from Practice P4 (running `npm run dev` in the wrong folder). Quote the message you saw and explain what it was telling you.
8. **Warning vs error.** After `npm install` you likely saw yellow warnings about "vulnerabilities." Explain why those are not the same as an error, and what you did about them.

### 2. `commands.md`

A copy-paste log of the exact terminal session you used, with a one-line comment above each real command saying what it did. Example format:

```text
# go to home folder
cd $HOME

# enter Desktop
cd Desktop

# scaffold the project
npm create vite@latest my-first-react-app
...
```

Redact anything private (like your username in a path); replace it with `<you>`.

### 3. `screenshot.png` (or `.jpg`)

One screenshot of your **browser** showing your running app at the `localhost` URL, with the URL bar visible so the port can be read. A second screenshot of the **terminal** showing `npm run dev` output is welcome but optional.

## Definition of done

- Folder named `U09-YourName` with all three files present.
- The screenshot shows a real running app with a visible `localhost` URL and port.
- `commands.md` reflects your actual session, not a copy of the lesson.
- If you could not get the app running, you submitted `answers.md` and `commands.md` with the exact error text and everything you tried.

## Note on stuck submissions

A documented failure is a valid submission. Never send nothing. Use the U00 stuck protocol and include your notes.
