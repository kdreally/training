# U08 Assignment — Node.js installed and verified

Submit the following to your trainer in **one folder or zip** named:

`U08-YourName`

## Files to submit

### 1. `answers.md`

Answer in your own words. Short paragraphs and bullet lists are both fine. Do not paste the lesson back unchanged.

1. **What Node is.** In 3–5 sentences, explain what Node.js is and why a course about designing interfaces needs it. Use the "workshop vs product" idea or your own words.
2. **Terminal vs shell.** What is a terminal? What is a shell? Name your shell (PowerShell, bash, or other).
3. **List command.** Write the exact command you used to list files, and paste (or type) two real folder names it printed.
4. **Move command.** Write the exact `cd` command you used to move into a folder, and the command you used to go back up. Say what the screen printed after each (the honest answer may be "nothing").
5. **Version check.** Paste the exact output of `node --version` and `npm --version`. State whether your Node major version (the first number) is 18 or higher.
6. **Error-reading practice.** Describe the deliberate error you made in Practice P3. Quote the error text (or a close paraphrase) and explain what the terminal was telling you.
7. **Fresh terminal.** Why does an already-open terminal sometimes fail to find a program you just installed? Answer in one or two sentences.
8. **PATH.** In your own words, what is PATH and how does it cause a `'node' is not recognized` error?

### 2. `install-log.md`

A short factual record of your install. Include:

- Your operating system and version (for example "Windows 11" or "macOS 14 Sonoma").
- Where you downloaded Node from (the URL).
- Which version you chose (LTS or another) and why.
- Roughly how long the install took.
- Any error text you saw, verbatim, and what you did about it.

### 3. `screenshot.png` (or `.jpg`)

One screenshot of your terminal showing the output of `node --version` and `npm --version` in the same window. The prompt and both version lines must be visible.

## Definition of done

- Folder named `U08-YourName` with all three files present.
- `answers.md` answers every prompt in your own words.
- Versions shown are real, not copied from this lesson.
- If your machine could not complete the install, you still submitted `answers.md` and `install-log.md` describing exactly where you got stuck and the error text.

## Note on stuck submissions

If you are blocked, a submission that documents the block is worth full effort marks. Submit anyway. Never submit nothing.
