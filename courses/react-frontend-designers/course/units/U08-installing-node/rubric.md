# U08 Rubric

Visible to learners. Total **20 points**.

| Criterion | Points | Must-have? | Evidence |
|-----------|--------|------------|----------|
| Explains what Node.js is and why the course needs it | 4 | Yes | `answers.md` Q1 |
| Correctly distinguishes terminal from shell | 3 | Yes | `answers.md` Q2, Q3 |
| Real list and move commands with honest output | 3 | Yes | `answers.md` Q3, Q4 |
| Both versions pasted and major version assessed | 3 | Yes | `answers.md` Q5, screenshot |
| Error-reading practice completed and decoded | 3 | Yes | `answers.md` Q6 |
| Explains fresh-terminal / PATH behavior | 2 | No | `answers.md` Q7–Q8 |
| Install log is factual and specific | 2 | No | `install-log.md` |

The screenshot is **evidence**, not a separate criterion; without it, cap the version-check criterion at 1/3 unless the answer is otherwise detailed.

### Partial credit notes (assessors)

- Q1: full only if it separates "runs the tooling" from "the finished page." "It runs JavaScript" alone earns 2/4.
- Q2: award 2/3 if they describe a terminal but call every shell "terminal"; 0 if no distinction at all. Do not require the word "shell" if the idea is present.
- Q4: "nothing printed" is the *correct* observation for a successful `cd`; award full. Penalize only a fabricated output that never appears.
- Q6: award full for a genuine attempt even if the error is not the exact one in the lesson. The learning target is reading, not memorizing.
- Q7–Q8: award partial (1/2) for a correct intuition without the word PATH.
- If the install failed: grade the documentation of *why* as if it were the install. Do not punish an honest, well-evidenced block. Refer to the stuck protocol in U00.

### Common weak submissions

- Versions copy-pasted from the lesson (identifiable and against the rule).
- `answers.md` restates headings with no personal output.
- No screenshot, no install log.
- Terminal/shell answer is "the same thing" with no attempt.
