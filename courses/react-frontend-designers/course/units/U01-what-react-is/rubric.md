# U01 Rubric

Visible to learners. Total **20 points**.

| Criterion | Points | Must-have? | Evidence |
|-----------|--------|------------|----------|
| Own-sentence definition of React includes "reusable" + "parts" (or a defined synonym) | 3 | Yes | `answers.md` Q1 |
| Describes a concrete human maintenance/reuse problem | 3 | Yes | `answers.md` Q2 |
| Names all three component aspects (structure, look, behavior) with examples | 3 | Yes | `answers.md` Q3 |
| Design bridge is accurate and specific (a genuinely reusable element) | 2 | No | `answers.md` Q4 |
| Names two correct "not React" items with a plausible confusion each | 3 | Yes | `answers.md` Q5 |
| Chain is ordered correctly and the "why" is sound | 2 | Yes | `answers.md` Q6 |
| Honest scope: one real aim + one real non-promise | 2 | No | `answers.md` Q7 |
| Predict-then-run answer is correct (one component, configured not recreated) | 1 | No | `answers.md` Q8 |
| `mental-model.md` corrects **both** learners with a reason | 3 | Yes | `mental-model.md` |
| Files named correctly; checklist present | 1 | Yes | folder/zip structure |

### Partial credit guidance

- **Q1:** 1/3 if "library" is described correctly but "reusable parts" is missing or unexplained.
- **Q3:** 1/3 per named aspect; 0 if the learner lists only visual aspects ("look") and misses structure/behavior.
- **Q5:** 2/3 for one solid item; 0 if the "not" items are actually true of React.
- **Q6:** full only if the order AND the reason are correct; 1/2 if order is right but the reason is vague.
- **mental-model.md:** 1.5/3 per learner corrected. A correct fix with no reason earns half of that learner's share.
- **Q8:** award the point if the learner says "no new component" *and* ties it to passing different content in (props is not required vocabulary here).

### Must-have vs nice-to-have

- **Must-have (fails the unit if absent):** Q1, Q2, Q3, Q5, Q6, and `mental-model.md`. These cover the unit's core outcomes.
- **Nice-to-have (points, but not a gate):** Q4, Q7, Q8.

Do not penalize imperfect English or design-tool choices. Penalize copy-pasted lesson text with no personalization on Q2, Q4, and Q7.
