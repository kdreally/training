# U01 Assignment — React in your own words

Submit the following to your trainer in **one folder or zip** named:

`U01-YourName` (use your real name or student id as they prefer)

## Files to submit

### 1. `answers.md`

Answer these prompts in your own words. Short paragraphs or bullets are fine. Do **not** paste the lesson text back unchanged — your trainer is looking for your understanding, not the lesson's wording.

1. **Translate the sentence.** Write your own one-sentence definition of React. It must contain the words *reusable* and *parts* (or a synonym you define).
2. **The human problem.** In 3–5 lines, describe the everyday problem React solves for a person building a page. Use your own scenario (a button, a card, a list — anything real to you).
3. **Component anatomy.** Name the three things a component bundles together, and give a one-line example of each for a component you know from a design file.
4. **Design bridge.** Complete this sentence and explain it: *"A React component is like a ______ in my design tool because ______."*
5. **What React is not.** List **two** things React is **not**, and for each, one sentence on why that could confuse a beginner.
6. **The chain.** Put these in the correct order and explain in one line why the order matters: *JavaScript changes the page · CSS gives it look · HTML gives it structure · components name reusable parts.*
7. **Honest scope.** Write one thing this course **does** aim to make you able to do, and one thing it deliberately does **not** promise.
8. **Predict then run (on paper).** In the worked example, one of the three notification cards needs different text. Predict whether that requires a whole new component. State your prediction, then state what the lesson says happens and why.
