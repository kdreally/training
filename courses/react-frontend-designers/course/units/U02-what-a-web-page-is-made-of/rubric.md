# U02 Rubric

Visible to learners. Total **20 points**.

| Criterion | Points | Must-have? | Evidence |
|-----------|--------|------------|----------|
| Explains HTML vs CSS with an original metaphor; each layer's job correct | 3 | Yes | `answers.md` Q1 |
| Defines the DOM accurately in their own words | 3 | Yes | `answers.md` Q2 |
| Explains the tree shape and uses parent/child/sibling correctly | 3 | Yes | `answers.md` Q3 |
| Distinguishes View Source vs Elements, with one valid reason they differ | 3 | Yes | `answers.md` Q4 |
| CSS rule described as "target → look" without claiming CSS is structure | 2 | Yes | `answers.md` Q5 |
| Predict-then-inspect recorded honestly, with a reflection if wrong | 2 | No | `answers.md` Q6 |
| Correctly decodes the "Save as" failure and names View Source | 2 | No | `answers.md` Q7 |
| `tree.md` valid: parent with ≥3 children and ≥1 grandchild, real page | 2 | Yes | `tree.md` |
| Tag names classified (holds content vs stands alone) correctly | 1 | No | `tree.md` |
| Files named correctly; checklist present | 1 | Yes | folder/zip structure |

### Partial credit guidance

- **Q1:** 1.5/3 if either layer's job is wrong or the metaphor is copied from the lesson. A correct but generic metaphor ("like a document") earns partial.
- **Q2:** full only if it captures "browser builds it from the HTML / it is the live structure the user sees." Copying "Document Object Model" with no plain meaning earns 1/3.
- **Q3:** 1/3 per correct relationship word in context, plus 1 for the nesting reason (reword). If the words are used backwards, award 0 for the words.
- **Q4:** 2/3 if the contrast is right but no reason is given; 0 if they insist the two are identical.
- **Q5:** accept any accurate "choose something, describe how it looks." Deduct if they claim CSS writes the structure/content.
- **Q6:** full for an honest prediction + observed result, even if the prediction was wrong. 0 if the learner clearly did not inspect (answers contradict a real DOM) or skipped the reflection.
- **`tree.md`:** 1 point for the parent-with-3+ shape, 1 point for the grandchild relationship. Deduct 1 (floor 0) if the tag names are invented (e.g., `<box>`, `<card>`, `<text>` — not HTML tags).
- **Tag classification:** 0.5 per correctly labeled element, capped at 1. `img`, `br`, and `input` stand alone; `div`, `p`, `h1`, `ul`, `li` hold content.

### Must-have vs nice-to-have

- **Must-have (unit fails without these):** Q1, Q2, Q3, Q4, Q5, and a valid `tree.md`.
- **Nice-to-have (points only):** Q6, Q7, the tag classification, checklist.

Do not penalize the choice of website, imperfect English, or a prediction that turned out wrong — honesty is the assessable skill in Q6.
