# U11 Assignment — Your first component

Submit the following to your trainer in **one folder or zip** named:

`U11-YourName`

## Files to submit

### 1. `answers.md`

Answer in your own words.

1. **Definition.** In one sentence, what is a React component?
2. **PascalCase.** Why must component names start with a capital letter? Include what React does differently for a lowercase name.
3. **Export and import.** If a file ends with `export default App`, write the exact `import` line a sibling file needs, and explain what "default" means here.
4. **Your edit.** Describe what you changed in `App.jsx` and paste the full, final contents of your `App.jsx`.
5. **The chain.** Which file renders `<App />`, and why did you not need to edit it in this unit?
6. **Design bridge.** Explain the component idea using a symbol/component you reuse in your design tool. Name what makes it reusable.
7. **Error-reading practice.** Paste the exact error text you saw when you broke the `export` on purpose in Practice P3. Explain, in your own words, what the message meant and how you fixed it.
8. **Lowercase experiment.** In Practice P5 you renamed `App` to `app`. What happened? Quote the error and explain why the capital letter matters.

### 2. `App.jsx`

Your actual working file. It must:

- Define a component named `App` (capital A).
- Return markup inside a single wrapping element.
- End with `export default App`.
- Include at least a heading and one paragraph of your own wording (not the lesson's).

### 3. `screenshot.png` (or `.jpg`)

One screenshot of your browser showing your component's text rendered on the page.

## Definition of done

- Folder named `U11-YourName` with all three files present.
- `App.jsx` is real code copied from your project, and the app runs from it.
- The screenshot matches the words in `App.jsx`.
- If the page stayed blank, `answers.md` includes the exact console/terminal error and everything you tried.

## Note on stuck submissions

A blank page plus an honest error log is a valid submission and earns effort marks. Never send nothing.
