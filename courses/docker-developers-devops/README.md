# Docker for Developers & DevOps

Learn containers from first principles: why images exist, how Dockerfiles work, how Compose ties services together, and how Docker fits real developer and DevOps workflows.

## Who this is for

Developers and DevOps-curious learners with some programming experience but little container experience. Confusion is normal; every command is explained before you run it.

## How learning works

| Role | What they do |
|------|----------------|
| Learner | Reads static unit materials, does exercises, completes assignments |
| Human trainer / assessor | Reviews submissions against each unit's rubric |
| Course author | Generates units from the teaching doctrine |
