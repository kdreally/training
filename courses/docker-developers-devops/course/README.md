# Course home — Docker for Developers & DevOps

Welcome. This course takes you from the "works on my machine" problem to confident, containerized delivery.

## How it works

1. Open the next unit folder under `units/`.
2. Read that unit's `README.md` in order — do not skip the "why."
3. Do the practice exercises.
4. Complete the assignment and submit it the way your trainer asked.
5. Use the **rubric** in the unit so you know how you will be scored.

You do **not** need to be fast. Confused is normal. Every unit explains new ideas before it asks you to use them.

## Order

Work units in ID order: `U00` → `U35`. Full list: [units/INDEX.md](./units/INDEX.md).

Do not skip ahead. Later units assume earlier ones.

## What you need

- A computer you can install software on (Windows, macOS, or Linux).
- Docker installed **when that unit arrives** (not before you are taught what it is).
- A text editor (any is fine; VS Code is a common free choice).
