# U01 Rubric

Visible to learners. Total **20 points**.

| Criterion | Points | Must-have? | Evidence |
|-----------|--------|------------|----------|
| Journey from source code to running container described, five or more stops named | 5 | Yes | `destination-map.md` Q1 |
| Each of the seven ideas matched to a sensible human problem | 4 | Yes | `destination-map.md` Q2 |
| Image vs container explained in own words; U08 noted as precise source | 3 | Yes | `destination-map.md` Q3 |
| Two capabilities and two exclusions, with a reason limits matter | 3 | Yes | `destination-map.md` Q4 |
| Chosen app is concrete and its needs are plausible | 2 | No | `destination-map.md` Q5 |
| One honest question about a fuzzy word is posed | 2 | No | `destination-map.md` Q6 |
| Files named correctly; checklist present and honest | 1 | Yes | folder / zip structure |

### Partial credit notes (assessors)

- Q2: award 2/4 if four or five matches are sensible; 0 if the list is copied verbatim from the lesson with no reasoning. Minor mis-mappings for `CI` and `deploy` are common and thoughtful — award half for those.
- Q3: award 1/3 if they describe a container well but cannot yet separate it from an image, provided they acknowledge the gap.
- Q4: award 1/3 if only exclusions are listed with no capabilities.
- Do not penalize imperfect English. Do penalize empty answers or pasted lesson text with no personalization, especially on Q5 and Q6.
- Q6 is a confidence check: any genuine question scores full marks. "None, it all made sense" is not a question; award 0 there but treat it as a signal, not a failure.
