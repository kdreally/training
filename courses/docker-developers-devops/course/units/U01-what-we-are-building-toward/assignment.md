# U01 Assignment — Your destination map

Submit the following to your trainer in **one folder or zip** named:

`U01-YourName` (use your real name or student id as they prefer)

## Files to submit

### 1. `destination-map.md`

Answer these prompts in your own words. Short paragraphs and bullet lists are both fine. Do not paste the lesson back unchanged.

1. **The journey.** In 7–10 lines, describe the path from "app source code on my laptop" to "the same app running elsewhere in a container." Mention at least five of the stops from the unit.
2. **Idea to problem.** For each of these ideas, write the human problem it solves: *image, container, Dockerfile, Compose, registry, CI, deploy.* One sentence each.
3. **Image vs container (first pass).** Explain the difference in your own words, then add the line: "I will learn the precise version in U08." This shows you know the difference between a preview and a full definition.
4. **Honest scope.** List **two** things this course will help you do and **two** things it will *not* cover. Then write one sentence on why knowing the limits is useful.
5. **Your target app.** Describe a small app you would most like to containerize by the end (real or imagined). Write three sentences about what it needs to run.
6. **Early confusion.** Name one word from this unit that still feels fuzzy. Write the exact question you would ask your trainer about it.

Copy this checklist and mark each item `[x]` when true:
