# U21 Rubric

Visible to learners. Total **20 points**.

| Criterion | Points | Must-have? | Evidence |
|-----------|--------|------------|----------|
| Names three or more concrete pains of manual `docker run` startup | 4 | Yes | `answers.md` Q1 |
| Explains "declarative" accurately with a reasonable analogy | 4 | Yes | `answers.md` Q2, Q6 |
| States two correct "Compose is not…" items with reasoning | 3 | Yes | `answers.md` Q3 |
| Distinguishes file names and command versions correctly | 4 | Yes | `answers.md` Q4 |
| "Before and after" shows two sensible `docker run` commands and a clear saving | 3 | No | `answers.md` Q5 |
| Real `docker compose version` output or decoded failure provided | 2 | Yes | `version-output.txt`, `checklist.md` |

### Partial credit notes (assessors)

- Q2/Q6: award full credit only if the analogy genuinely maps to "describe the result, not the steps." A vague "it's simpler" earns 1/4.
- Q4: award 2/4 if they know the file names but confuse the command versions (or vice versa).
- Q3: award 1/3 per correct item; accept "not a Dockerfile replacement" and "not Kubernetes" as the strongest answers.
- Do not penalize imperfect English. Do penalize a plainly copy-pasted lesson restatement with no personalization on Q1 or Q2.
- `version-output.txt` showing a well-explained failure is full credit — we are testing understanding, not luck.
