# U03 Assignment

Submit: `U03-YourName` → `answers.md`

1. Define value, expression, evaluate, literal, type (own words).
2. Table with 6 literals: write each literal, its type, one sentence use-case.
3. Evaluate (show steps if multi-step):  
   a) `2 + 3 * 4`  
   b) `(2 + 3) * 4`  
   c) `"Hi " + "there"`  
   d) `11 % 4`  
   e) `8 === 8`  
   f) `8 === "8"`  
   g) `"2" + 2`
4. Explain in 3–6 sentences why `"2" + 2` differs from `2 + 2`.
5. Mark each as expression-like or statement-like and why:  
   - `100`  
   - `100 + 1`  
   - `let score = 100 + 1;`  
   - `false`
