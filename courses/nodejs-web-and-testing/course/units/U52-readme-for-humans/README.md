# U52 — README and run instructions for another human

**Phase 6**

## Where you are

Code works for you. A README must make it work for **someone else**.

## What you will be able to do

- Write a README with purpose, setup, run, test, examples.
- Anticipate missing Node/npm knowledge at a light level (link to course ideas, not rewrite U12).
- Include troubleshooting tips (port in use).

## What you need already

- A project (capstone)

## Time and energy

**40–70 minutes.**

## Why this exists

Unrunnable projects fail assessment and collaboration.

## Plain-language teaching

### README sections (minimum)

1. Project name + one-paragraph purpose  
2. Requirements (Node version)  
3. Install  
4. Start  
5. Test  
6. Example requests  
7. Notes on in-memory data  
8. Troubleshooting  

### Write commands in copy-paste blocks

```bash
npm install
npm test
npm start
```

### Audience

Assume assessor is skilled but new to *your* repo. Do not assume they know your folder layout without map.

## Vocabulary

| Term | Plain meaning |
|------|---------------|
| README | First human doc in a project |
| Repro steps | How to reproduce run |

## Worked example

Polish capstone README to include all sections.

## Common errors

### Error: Only screenshots of code

Commands matter.

### Error: Secret absolute paths from your machine

Use relative paths.

## Checkpoints

1. Eight sections?
2. Why Node version?
3. Why example curls?
4. One troubleshooting item?
