# U01 Assignment — Destination map

Submit folder/zip: `U01-YourName`

## `answers.md`

1. **Destination.** Write the course destination in your own words (4–8 sentences). Include: Node.js, backend/HTTP, automated tests.
2. **Order.** List phases 0–5 in order. For each, one plain sentence.
3. **Why order matters.** Give one example of a “cruel day-one command” and what hidden ideas it contains.
4. **Scope.** Name two things in scope and two out of main-path scope.
5. **Testing place.** Where does testing sit in the journey? (Not “at the end and ignore until then.”)
6. **Personal goal.** What would *you* like to be able to build by the end (keep it small and honest)?

## `checklist.md`

```markdown
- [ ] I can state the destination without reading.
- [ ] I accept the phase order even if I am impatient for “web.”
- [ ] I read the rubric.
```

## Definition of done

All questions answered in your own words; checklist complete.
