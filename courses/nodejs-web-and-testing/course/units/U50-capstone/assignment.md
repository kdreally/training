# U50 Capstone Assignment — `U50-YourName`

Submit project folder (zip) with source, package.json, lockfile, tests, README. No node_modules unless required.

## Definition of done checklist (include as `CHECKLIST.md`)

```markdown
- [ ] GET /health
- [ ] CRUD-ish list/get/create (min)
- [ ] Validation 400s
- [ ] In-memory store
- [ ] ≥6 unit tests
- [ ] ≥5 HTTP tests
- [ ] npm test green
- [ ] npm start works
- [ ] README complete
- [ ] answers.md reflection
```

## `answers.md`

1. Architecture tour (files).
2. What you tested at which layer and why.
3. Hardest bug + how tests helped (or would have).
4. What you would add with one more week.
