# Node.js Web & Testing

A backend-first course from first principles: programming, Node.js, HTTP APIs, and automated tests, then a plain-browser frontend and Playwright.

**Published site:** https://kdreally.github.io/training/nodejs-web-and-testing/

## Who this is for

Learners who have touched code before but are not confident yet, especially around Node, packages, servers, and testing. Confusion is treated as normal. Every new idea is explained before any task that needs it.

## How learning works

| Role | What they do |
|------|----------------|
| Learner | Reads static unit materials, does exercises, completes assignments |
| Human trainer / assessor | Reviews submissions against each unit's rubric |
| Course author | Generates units from the teaching doctrine |

There is no assumption of a live tutor in the room. Each unit stands alone.
